# Gate 3.1B.1 — promoção local do GPT-6 Luna

Estado em 2026-09-23: o modelo oficial **preparado no codebase e no `.env.local` deste worktree** para a Secretária Everflair é `gpt-6-luna`. A Golden Battery V2 passou 10/10 casos funcionais em ambiente local descartável, sem confirmação, escrita operacional, hosted tool ou container. Isto não é deploy nem mudança de produção. O modelo anterior, `gpt-5.6-luna`, permanece na allowlist como rollback temporário e identifica os baselines históricos; não reclassificar esses registros como GPT-6.

A seleção runtime continua explícita em `SALON_SECRETARY_MODEL`; a ausência da variável falha fechada. `.env.example` indica `gpt-6-luna` e a configuração local ignorada pelo Git usa o mesmo valor. Rollback local: definir `SALON_SECRETARY_MODEL=gpt-5.6-luna`, mantendo `SALON_SECRETARY_ALLOW_PAID_CALLS=false` até uma execução paga separadamente autorizada. O precheck de fixtures V2 aceita ambos os IDs aprovados, sem mudar mensagens, gabaritos, referências ou o baseline histórico.

O cost guard existente continua exigindo `POST /v1/responses`, uma Function Tool local, `store=false`, `parallel_tool_calls=false` e nenhum estado/prompt hospedado. Containers, `container_auto`, shell, Code Interpreter, buscas web/arquivo, Computer Use, geração de imagem, hosted MCP, hosted tool search, arquivos e vector stores seguem bloqueados antes da rede. O Agent mantém tracing desativado, `retry.maxRetries=0` e `maxTurns=1`. A estimativa GPT-6 Luna usa sua tarifa própria de input, cached input, cache write e output; reasoning já integra output. A telemetria HTTP individual do caso 6 da V2 não foi recuperada, embora a inferência, o uso e a proposta funcional tenham sido persistidos. Por isso, estatísticas HTTP da bateria foram apresentadas sobre nove casos medidos, com a latência de interpretação do caso 6 separada.

JEV permanece exclusivamente em avaliação, com `NO_ACCEPTANCE_POLICY`, sem router produtivo. As seis Skills, Registry, drafts, propostas, confirmação, RLS, Outbox e banco não foram alterados por esta promoção. Nenhuma chamada OpenAI/JEV, alteração administrativa remota ou deploy integra o Gate 3.1B.1.
